## About the project

- This portfolio represents my journey as a frontend developer who enjoys combining code, design, motion and storytelling.

- The main goal was to create more than a traditional portfolio. I wanted to build an interactive experience where animations, visual details and storytelling are part of the website itself.

## What I focused on

- Creative animations and transitions
- CSS Art and custom visual compositions
- Interactive UI and custom components
- Storytelling through animations and user interaction
- Responsive and Adaptive Design
- Performance and user experience
- Accessibility and Screen Reader Support

## Built with

- Vite
- HTML5
- SASS ( SCSS - BEM )
- Vanilla JavaScript
- TypeScript
- GSAP
- Three.js

## Performance

- Lighthouse Score:
  - Performance: 99
  - Accessibility: 100
  - Best Practices: 100
  - SEO: 100

## Features

- Interactive intro scene created with CSS Art and GSAP. ( Pacman and Ghost )
- Animated storytelling section with custom characters, sound effects and GSAP timelines. ( Gate Overlay, My Story and My Process Sections )
- CSS Art illustrations and custom visual experiments. ( Oldschool TV, Envelope, Pacman, Ghost )
- Custom video player with accessibility support. ( Showcase Section )
- Full Screen Reader descriptions for interactive storytelling sections. ( Intro, My Story, etc.)
- Responsive and adaptive design for different devices and browsers.
